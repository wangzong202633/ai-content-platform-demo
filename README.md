# 企业AI营销内容智能管理平台 · Demo

黑客松演示项目 —— **"AI 生成 + 老板偏好沉淀"飞轮** 与 **"一份素材 × 5 渠道"适配**，基于
《PRD V1.0》《系统架构设计文档 V1.0》《黑客松Demo方案》落地。

## 5 分钟启动

```bash
# 1. 后端（FastAPI + SQLite，零外部依赖）
cd backend
pip install -r requirements.txt
python -m uvicorn app.main:app --port 8000

# 2. 前端（Vite + React 18 + AntD 5）
cd frontend
npm install
npm run dev          # http://localhost:5173

# 或 Docker 一键部署（构建前端 + 单容器运行，访问 http://localhost:8000）
docker compose up --build -d
```

> 默认**离线剧本模式**（`DEMO_OFFLINE=1`）：不依赖任何大模型 API，永不翻车。
> **当场真生图/真生文（豆包·火山方舟）**：Key 已配好并验证，只差两步——
> ① 火山方舟控制台 → 模型推理 → 开通管理，开通 **Doubao-Seed-1.6-Flash**（文本）和 **Doubao-Seedream-4.0**（图像）；
> ② 把 `backend/.env` 里 `DEMO_OFFLINE` 改为 `0` 并重启后端。界面自动亮"实时大模型/实时生图"绿色徽章，无需改一行代码。
> 降级链（已演练）：真实调用失败 → 缓存 → 剧本/模板合成兜底，任何一层失败演示照常进行；配色守卫双向锁定 v1 深色 / v2 浅色，live 模式下飞轮剧情依旧确定。

## 工程结构

```
demo/
├─ backend/               # FastAPI 模块化单体（V1.0 同构）
│  ├─ app/
│  │  ├─ api/             # contents(SSE生成/适配/审核) / preferences / misc(指标)
│  │  ├─ core/
│  │  │  ├─ prompt_engine.py   # Prompt 四层拼装（角色→知识注入→任务→示例）
│  │  │  ├─ preference.py      # 偏好引擎：提取→主管确认→注入
│  │  │  ├─ workflow.py        # 内容状态机（PRD 4.5 七态）
│  │  │  ├─ llm.py             # 三级降级：缓存→API→剧本
│  │  │  └─ scripted.py        # 离线剧本（v1/v2 内容、渠道模板、信号）
│  │  ├─ db.py / seed.py       # SQLite + 种子数据（含历史审核轨迹）
│  │  └─ main.py
│  ├─ cache/              # LLM 结果哈希缓存（预烘焙兜底）
│  └─ .env.example
├─ frontend/              # Vite + React 18 + TS + AntD 5
│  └─ src/pages/          # 工作台/内容生成/审核中心/偏好中心/数据看板/详情对比
│     └─ components/      # ContentPreview(设计调色板) / ChannelFrames(5渠道Canvas) / TrendChart(SVG)
└─ README.md
```

## Demo → V1.0 回迁路径（"不是玩具"论据）

| Demo 实现 | V1.0 替换 | 成本 |
|-----------|----------|------|
| SQLite | PostgreSQL 15 | 换连接串 |
| 规则匹配偏好检索 | Milvus/Chroma 向量检索 | 实现 Retriever 第二后端 |
| BackgroundTasks | Redis + Celery | 换队列壳 |
| 剧本/缓存 LLM 层 | 模型分级路由（4级） | 路由表已留位 |
| 单文件部署 | Docker Compose 单机 4C8G | compose 已规划 |

核心模块（状态机 / Prompt 引擎 / 偏好提取与注入）**按架构文档 V1.0 设计编码**，赛后无需重写。
